아래 변수값을 기준으로 `visibleScene`과 `openingLine`을 생성하라.

<user_profile>
성별: {{user_gender}}
나이: {{user_age}}
</user_profile>

<persona>
id: {{persona_id}}
이름: {{persona_name}}
성별: {{persona_gender}}
나이: {{persona_age}}
제목: {{persona_title}}
설명: {{persona_description}}
핵심 갈등: {{inner_conflicts}}
복음 장벽: {{gospel_barriers}}
말투: {{speech_style}}
</persona>

<session>
관계: {{relationship}}
상황: {{setting}}
훈련 초점: {{goal}}
</session>

<case_id>
{{case_id}}
</case_id>

작업:
- 사용자가 처음 보게 되는 첫 장면을 만든다.
- `visibleScene`은 채팅 상단에 표시될 3인칭 현재 장면 설명이다.
- `openingLine`은 그 장면 안에서 페르소나가 실제로 처음 꺼내는 첫 말풍선 대사다.
- 사용자는 이 장면 앞의 대화나 사건을 모른다.

생성 기준:
- `visibleScene`과 `openingLine`을 한 쌍으로 봤을 때 현재 장면, 페르소나의 상태, 대화가 시작될 방향이 이해되어야 한다.
- `openingLine`은 실제 사람이 처음 꺼낼 수 있는 자연스러운 말이어야 한다.
- 가벼운 인사, 장소 반응, 어색한 첫마디도 허용된다.
- 단, `openingLine`이 가볍거나 일반적이면 `visibleScene`에는 페르소나의 망설임, 감춘 압박, 관계 거리감, 신앙/교회에 대한 조심스러움, 오늘 대화가 시작될 이유 중 하나가 반드시 드러나야 한다.
- `visibleScene + openingLine` 조합은 훈련 초점에 맞는 연습 기회를 만들어야 한다.
- 훈련 초점은 사용자가 연습할 과제다. 페르소나가 먼저 복음/부활/죄/구원 내용을 꺼내거나 설명을 시작하면 안 된다.
- 사용자가 그 방향으로 열 수 있도록 일상 고민, 가치관, 오해, 거리감, 질문의 여지만 제공한다.
- 처음 만난 사람 또는 안면만 있는 사람이면 기본적으로 존댓말을 사용한다.
- 친밀 호칭은 관계가 충분히 가까울 때만 사용한다.
- 호칭이 애매하면 이름/호칭을 생략하고 존댓말로 말한다.
- 페르소나의 고민이나 복음 장벽은 너무 노골적인 고백문이 아니라 10~30% 정도만 묻어나게 한다.

상황 해석:
- `페르소나가 고민을 처음 꺼내려는 순간`이면 이미 말한 고민을 가리키지 말고, 고민 내용이나 압박감이 현재 장면에 보여야 한다.
- `신앙/교회 이야기가 대화의 문턱에 올라온 첫 순간`이면 "그 주제"라고 쓰지 말고 신앙/교회/하나님 중 하나를 직접 써도 된다.
- 과거 신앙 대화가 있는 관계라도 "저번 그 얘기"처럼 구체 내용 없는 과거 지시는 쓰지 않는다. 현재의 조심스러움이나 남은 거리감으로 표현한다.

금지:
- 보이지 않는 앞맥락 지시: 이런 얘기, 저런 얘기, 그 이야기, 그 얘기, 저번에 하던 거, 아까, 방금, 계속 생각나던 것, 꺼내는 게, 꺼내놓고, 말한 것처럼
- 사용자가 아직 하지 않은 말을 전제하는 표현
- 설명문, 번호, 마크다운, 내부 분석, QA 메모

출력 형식:
JSON 객체 1개만 출력하라. 코드블록과 설명은 출력하지 마라.

{
  "id": "{{case_id}}",
  "visibleScene": "35~85자 정도의 3인칭 현재 장면 설명",
  "openingLine": "14~40자 정도의 자연스러운 첫 말풍선 대사"
}
