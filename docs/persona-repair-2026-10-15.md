# 페르소나 기억·피드백 수정 기록 — 2026-10-15

이번 사용자 승인으로 시작한 새 수정 기록이다. 앞선 task 7·9의 미완료 종료 기록과 비용 원장은 그대로 보존했다. 운영 배포, 원격 프롬프트 게시, 운영 데이터 변경은 하지 않았다.

## 결과와 적용 범위

신규 설치 기본값은 대화 `gpt-6.1-sol / low / 1536`, 피드백 `gpt-6.1-sol / low / 4096`으로 변경했다. 대화의 실제 주인, 잘못된 자기 사과, 근거 없는 피드백을 같은 입력에서 비교한 결과에 따른 품질 우선 선택이다. 전체 페르소나·시나리오의 모델 순위나 출시 품질 합격을 뜻하지 않는다. 기존 환경변수와 저장된 관리자 설정은 계속 우선한다.

검증된 범위에서는 경험의 주인을 바로잡고, 해소된 오해와 남아 있는 신앙 장벽을 구분하며, 성급한 결단 요구에 선을 그었다. 피드백은 실제 압박과 그 뒤의 사과를 함께 평가했다. 실제 사용자 대상 교육 효과와 장기적인 오류율은 측정하지 않았다.

## 구현

- 정본 대화 전체를 화자별 번호와 JSON 문자열로 전달한다. 줄바꿈·인용도 원문 그대로 보존한다. 경험·약속의 당사자와 명시적 정정을 우선하며, 잘못된 되짚기나 잘못된 동의를 새 사실로 취급하지 않도록 했다.
- 자신이 실제로 틀린 기록이 있을 때만 사과하도록 했다. 이미 들은 걱정을 모른다고 되묻지 않고, 현재 발화에 먼저 답하도록 했다. 채팅 턴에는 별도 기억 추출 모델 호출을 추가하지 않았다.
- 피드백의 형식·정확한 인용 검사에 항목별 의미 검증을 추가했다. 모든 항목에 실제 당사자, 근거 메시지, 반대 근거와 판정을 요구한다. 잘못된 지적이나 이미 한 과제는 한 번만 수정한다.
- 피드백은 최대 초안 2회·검증 2회다. 검증 실패·잘림·잘못된 구조에서는 보고서를 저장하거나 보여주지 않고 대화 기록을 보존한다. 실패·수정·검증 호출도 비용에 포함하며 월 예산을 다시 확인한다.
- 검증의 형식과 근거 인덱스는 코드로 검사하지만 의미의 참·거짓 자체는 모델 판단이다. 잘 정형화된 오판도 가능하므로 아래 실제 실패 기록을 삭제하지 않았다.
- Sol의 문맥 용량, 입력·캐시·출력 단가, 허용 추론 강도를 반영했다. 지원하지 않는 샘플링 인자는 보내지 않는다. 관리자 모델 선택과 저장 설정도 연결했다. 로그인·대화 기록·다시 연습 기능은 유지했다.
- 관리자 설정 저장은 정상인데 새 설정을 받는 화면 효과가 성공 안내를 지우는 기존 오류도 수정했다. 성공 안내는 유지하고 사용자가 다시 편집하거나 저장할 때 초기화한다.

### 테스트 진행기 수정

`controller-fixed-v3`는 앞선 명시적 주제 거절도 유지한다. 이후의 가벼운 대화를 새 동의로 해석해 필수 회상 질문을 끼워 넣지 않는다. 보수적으로 강제 질문을 막으므로 실제 새 동의가 있어도 자동 커버리지를 보장하지 않는다. 부족한 커버리지는 그대로 미완료다.

새 회귀 검사와 실제 Sol D1 원문을 사용한 오프라인 재현에서 U23의 원래 안전한 응답은 유지되고, 강제 회상은 차단되며, 평가 복제본의 필수 항목은 미완료가 된다. 원본 D1 기록은 바꾸지 않았다. v3를 적용한 새 유료 24턴 평가는 하지 않았다.

출력 상한은 실제 출력 요구량이 아니다. 낮은 추론 강도, 짧은 구어체, 피드백 항목 축소, 최대 호출 횟수 제한으로 비용을 관리한다. 피드백 초안이 출력 한도로 잘린 경우에만 두 번째 초안의 한도를 늘리는 기존 복구 경로가 있으며, 새 기본값에서는 8192가 될 수 있다. 이 비용도 집계한다. 정본을 요약해 기억을 잃는 방식은 사용하지 않았다. 긴 대화와 재시도에서는 비용이 증가한다. 저가 모델 선택지는 관리자 화면에 남겼지만 같은 품질을 보증하지 않는다.

## 적용과 남은 한계

운영 저장 설정은 자동 변경하지 않았다. 관리자 설정에 다른 모델이나 출력 상한이 저장되어 있다면 새 기본값이 덮어쓰지 않는다. 원격 Langfuse 프롬프트가 있으면 로컬 프롬프트보다 우선한다. 로컬 fallback 변경은 서버 재시작이 필요하다. 이전 task 8의 rollout payload는 이번 수정 전체를 담은 배포물이 아니다.

전체 6개 페르소나·12개 시나리오/14개 경로의 품질, 실제 초보 사용자의 학습 효과, 운영 OAuth/Supabase/Langfuse 통합, 컨테이너 실행은 이번 수정에서 모두 검증한 것이 아니다. 모델의 의미 검증에도 오판 가능성이 남는다. 이번 결과를 사람과 구별되지 않는 수준 또는 전면 출시 승인으로 표현하지 않는다.
